# Cómo acreditar

## Arte y documentación — CC BY 4.0

La licencia exige cuatro datos (fórmula **TASL**): **T**ítulo, **A**utor,
**S**ource (fuente) y **L**icense (licencia), más indicar si hubo cambios.
No hace falta pedir permiso para uso comercial.

Datos fijos:

| Campo | Valor |
|---|---|
| Título | «Solidaridad» — paquete de emoticones |
| Autor | osarevalo |
| Fuente | https://github.com/osarevalo/solidaridad-emoticon |
| Licencia | CC BY 4.0 — https://creativecommons.org/licenses/by/4.0/ |
| Cambios | describir brevemente (p. ej. «recoloreado», «reescalado», «versión 24 px») |

### Ejemplos listos para copiar

**Markdown / README:**

```markdown
«Solidaridad» por [osarevalo](https://github.com/osarevalo/solidaridad-emoticon),
licencia [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
Cambios: recoloreado a #2B7A78.
```

**HTML (pie de página o créditos):**

```html
<p>
  <a href="https://github.com/osarevalo/solidaridad-emoticon">«Solidaridad»</a>
  por osarevalo, licencia
  <a href="https://creativecommons.org/licenses/by/4.0/">CC BY 4.0</a>.
  Cambios: recoloreado y escalado.
</p>
```

**Créditos de video / presentación:**

```text
Emoticones «Solidaridad» — osarevalo (github.com/osarevalo/solidaridad-emoticon)
CC BY 4.0 — cambios: recoloreado.
```

**Impreso (sticker, folleto):**

```text
«Solidaridad» © 2026 osarevalo · CC BY 4.0 · github.com/osarevalo/solidaridad-emoticon
```

**Derivados (versión propia):**

Incluí la atribución anterior y añadí una línea: «Basado en “Solidaridad” de
osarevalo (CC BY 4.0); cambios: …». La obra derivada puede licenciarse como
quieras, siempre que la atribución y el enlace a CC BY 4.0 se conserven y no se
impongan restricciones adicionales sobre el material original.

## Código — MIT

Al redistribuir copias sustanciales de `scripts/`, `Makefile` o `package.json`,
conservá el aviso de copyright y el texto de permiso de `LICENSE`. No hay
obligación de atribución en la interfaz.

## Lo que no hace falta

- Pedir permiso para usar el arte, incluso comercialmente.
- Pagar regalías.
- Compartir tus modificaciones (CC BY 4.0 no es «compartir igual»).

## Lo que no se permite

- Implicar que osarevalo respalda tu producto o proyecto.
- Aplicar DRM o términos que restrinjan los derechos que la licencia concede.
- Usar el nombre o logo como marca registrada: la licencia no cede derechos de
  marca.
